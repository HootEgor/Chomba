## Project Description

Chomba is a mobile application for playing the card game of the same name. It allows users to play solo games, or play online with friends through a room-based system. The app tracks player scores, game history, and provides a leaderboard.

**Features:**
*   **Game Modes:** Play either a "Solo Game" or an "Online game".
*   **Online Multiplayer:** Create and join game rooms to play with other people. Share room codes or browse public rooms.
*   **Game State Management:** The app tracks rounds, scores, and player turns.
*   **Saved Games:** Save your games and resume them later.
*   **Authentication:** Sign in with Google or your email to keep your profile and game history.
*   **Voice Commands:** Use your voice to input scores.
*   **Leaderboard:** See how you rank against other players.
*   **Player Management:** Add players, and even merge player profiles.
*   **QR Code Joining:** Join online games quickly by scanning a QR code.

**Getting Started:**
1.  Clone the repository.
2.  Open the project in Android Studio.
3.  Set up your Firebase project and add your `google-services.json` file to the `app` module.
4.  Build and run the application.
